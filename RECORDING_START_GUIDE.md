1. Open OBS Studio
2. Click "+" under Sources → "Display Capture" (or "Window Capture")
3. Select your monitor or browser window
4. Click "+" under Sources → "Audio Input Capture"
5. Select your microphone
6. Click "Start Recording"

## 🎙️ AUDIO RECORDING TIPS

1. **Speak Clearly**: Every word should be distinct
2. **Slow Down**: Give yourself time between sentences
3. **Pause**: 2-second pause between sections
4. **Volume**: Keep consistent (not too loud/soft)
5. **Avoid Filler**: Don't say "um", "uh", "like"
6. **Natural**: Don't sound robotic
7. **Emphasize**: Speak with enthusiasm about features

---

## 🖱️ MOUSE MOVEMENT

1. **Slow**: Move cursor deliberately
2. **Highlight**: Keep cursor on UI element for 2+ seconds
3. **Click Gently**: Don't rapid-click
4. **Zoom**: Viewers need to see small text clearly
5. **Cursor Highlight**: Enable OBS cursor highlighting

---

## 📝 FORM FILLING SPEED

**Slow enough for viewers to follow**:
- Type each value slowly
- Pause 1 second after each field
- Point cursor at field before typing
- Speak while typing: "Now I'll enter the income..."

**Example typing pattern**:
```
"Now I'll enter the income field..."
[Point cursor at field]
[Slowly type: 750000]
[Pause 1 second]
"Now the employment type..."
[Click dropdown]
```

## ⚠️ COMMON MISTAKES TO AVOID

❌ **Too Fast**: Viewers can't follow
❌ **Silent**: Say what you're doing
❌ **Rambling**: Stick to script
❌ **Cluttered**: Close other applications
❌ **Unclear Audio**: Test microphone
❌ **Small Text**: Zoom browser to 125%
❌ **Mistakes**: Don't restart - just continue

---

## ✅ IF YOU MAKE MISTAKES

**Don't Restart!** Just continue. In OBS:
- You can always edit or cut sections later
- Just pause 2 seconds and repeat
- Or continue to next section

Example:
- If you stutter: Pause, take breath, continue
- If you click wrong: Say "Oops, let me try that again" and click correct one
- If page loads slow: Just comment on it: "While the page loads, let me explain..."


```bash
1. Open OBS Settings
2. Go to Audio
3. Check Desktop Audio and Mic are enabled
4. Do a test recording
```

```
- Output: 1920x1080
```
