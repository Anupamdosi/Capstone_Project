🎙️ RECORDING TIPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

AUDIO:
  ✓ Speak clearly and slowly
  ✓ Use natural tone (not robotic)
  ✓ Pause 1-2 seconds between major points
  ✓ Test microphone before recording
  ✓ Avoid background noise
  ✓ Consistent volume level
  ✓ Don't say "um", "uh", "like"

VIDEO:
  ✓ Zoom browser to 125% for readability
  ✓ Move cursor slowly and deliberately
  ✓ Keep cursor still on UI elements (2+ seconds)
  ✓ Click gently (don't rapid-click)
  ✓ Close all other applications
  ✓ Full screen the browser/application
  ✓ Use cursor highlighting in OBS

⚙️ OBS STUDIO SETUP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. INSTALL OBS:
   • macOS: https://obsproject.com/download
   • Windows: https://obsproject.com/download
   • Linux: sudo apt-get install obs-studio

2. SETUP VIDEO SOURCE:
   • Click + under "Sources"
   • Select "Display Capture" or "Window Capture"
   • Choose your monitor or browser window
   • Resize to fill preview area

3. SETUP AUDIO SOURCE:
   • Click + under "Sources"
   • Select "Audio Input Capture"
   • Choose your microphone
   • Test levels (should be green, not red)

4. CONFIGURE SETTINGS:
   • Output Resolution: 1920x1080
   • Frame Rate: 30 fps
   • Bitrate: 6000-8000 kbps
   • Encoder: Hardware (H.264 if available)

5. SET OUTPUT FOLDER:
   • File → Settings → Output
   • Set recording path to desired folder
   • Click "OK"

6. TEST RECORDING:
   • Do 30-second test
   • Click "Start Recording"
   • Record 30 seconds
   • Click "Stop Recording"
   • Play back to verify audio/video

DO NOT RESTART! Just continue:

• Stutter/Mispronounce: Pause 2 seconds, take breath, repeat word
• Wrong Click: Say "Let me try that again" and click correct button
• Page Takes Time to Load: Comment on it ("While that loads...")
• Forgot Next Step: Check script on side monitor, resume smoothly
• Said Something Wrong: Pause, continue to next point

Remember: You can always edit video later if needed! Just keep recording.
